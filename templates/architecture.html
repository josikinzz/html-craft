06
Tenancy

Multi-tenant — each agent gets an isolated database at {agentDir}/intelligence/feedback.db with per-agent config overlay and credential isolation.

Why isolated databases?

Per-agent stores keep tenant data physically separate, make deletion trivial, and let each agent tune its own embedding index without cross-tenant contention.
