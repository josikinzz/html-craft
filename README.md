# Visual Explainer

A personal installation snapshot of the `visual-explainer` agent skill. It generates self-contained HTML pages for diagrams, diff reviews, plan reviews, slides, and data tables.

See [`SKILL.md`](./SKILL.md) for usage and behavior.

## Install

Clone this repository into your agent skills directory:

```sh
git clone https://github.com/josikinzz/visual-explainer.git ~/.agents/skills/visual-explainer
```
